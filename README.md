AI Resume Evaluator & Job Matcher
=================================

A sleek, AI-powered web application that helps users upload resumes, receive smart feedback, and get matched with relevant jobs — built using React, Vite, TailwindCSS, TypeScript, and OpenAI/Supabase integrations.

--------------------------------------------------

🚀 Features
-----------
- Upload your resume in PDF format
- AI-Powered resume feedback (GPT-4o, LangChain)
- Smart job matching based on your skills
- Fully responsive UI with TailwindCSS
- Secure storage and resume parsing
- Built for speed using Vite

--------------------------------------------------

🛠️ Tech Stack
-------------
- Frontend: React, TypeScript, Tailwind CSS, Vite
- Icons: Lucide React
- UI: Radix UI Accordion
- Backend (optional): Supabase
- AI: OpenAI GPT-4o, LangChain

🧑‍💻 Getting Started
--------------------
1. Clone the repo:
   git clone https://github.com/your-username/ai-resume-evaluator.git
   cd ai-resume-evaluator

2. Install dependencies:
   npm install

3. Start development server:
   npm run dev
